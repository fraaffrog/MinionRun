# 🟡 Minion Clicker – WPF Game

**Minion Run** is a simple and fun interactive game developed using C# and Windows Presentation Foundation (WPF). The goal is to click on a Minion image that randomly moves across a 3x4 grid. Each successful click increases your score, and when you reach 10 points, you win!

---

## 🎮 Features

- ✅ Clickable Minion that moves around the grid
- 🧠 Score tracking with live updates
- ❌ Positions already clicked are marked with an “X”
- ⏱️ Time tracking label
- 🏆 Victory message once the player reaches 10 points
- 🎨 Simple and intuitive graphical interface

---

## 🧰 Technologies Used

- **Language:** C#  
- **Framework:** .NET with WPF  
- **Libraries:** System.Windows.Threading, System.Windows.Media, System.Windows.Controls
